# Audit Service

The **Audit Service** is a microservice responsible for tracking and logging domain events generated by the SkillBridge application, such as bookings, user logins, cancellations, and other core interactions.

## Architecture

It is composed of two main applications:

1. **Backend (`audit-service/backend`)**: A Spring Boot application that acts as a Kafka Consumer. It listens to event topics and persists recent events in a repository. It also exposes a REST API to query these events and general statistics.
2. **Frontend (`audit-service/frontend`)**: A modern Angular 20 application styled with **Tailwind CSS**, providing a professional dashboard for administrators. It shows interactive statistics, a live list of the latest audit events with filtering and search capabilities, and detailed payload inspection.

## Components

### Backend API Endpoints

- `GET /api/audit/events`: Returns the list of latest recorded events.
- `GET /api/audit/events/{eventId}`: Returns details of a specific event.
- `GET /api/audit/stats`: Returns aggregated statistics of the events (e.g., Bookings Created, Cancelled, Logins, etc.).

### Frontend Dashboard

The newly redesigned Frontend Dashboard features:
- **Tailwind CSS (v4)**: Utilized for a clean, responsive, and modern Admin Dashboard interface.
- **Angular 20 Signals**: Reactive state management for events and UI states.
- **Live Polling**: Automatically fetches new events and stats every 10 seconds to keep administrators updated without manual reloads.
- **Advanced Filtering & Search**: Quickly filter events by Type, Action, Role, or Resource, and search by ID or Username.
- **Detailed Event Inspection**: A modal drawer to view the complete JSON payload and metadata of any event.
- **Authentication Interceptor**: Integrates with the main application's JWT mechanism (`skillbridge_token` from localStorage) to authorize API requests securely.

## How to Run

The audit service is integrated into the main `docker-compose.yml`. You can start it along with the rest of the infrastructure:

```bash
docker compose up -d audit-backend audit-frontend
```

Alternatively, to run the frontend locally:
```bash
cd audit-service/frontend
npm install
npm start
```

Once running:
- The **Backend API** will be accessible at [http://localhost:8081](http://localhost:8081).
- The **Frontend Dashboard** will be accessible at [http://localhost:8090](http://localhost:8090) (or `http://localhost:4200` if running locally via `npm start`).

## Kafka Integration

The service connects to the existing Kafka cluster via the `KAFKA_BOOTSTRAP_SERVERS` environment variable (`kafka:29092` inside Docker). It subscribes to topics using the `audit-service-group` consumer group.
